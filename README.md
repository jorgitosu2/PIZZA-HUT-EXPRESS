# Pizza Hut Express – Landing Amarket

Landing gratuita, responsive y lista para subir a GitHub Pages.

## Archivos
- index.html
- styles.css
- script.js
- flyer.jpg

## Publicarla gratis con GitHub Pages
1. Crea una cuenta gratuita en GitHub si aún no tienes una.
2. Crea un repositorio nuevo, por ejemplo `pizzahut-express-amarket`.
3. Sube los 4 archivos de esta carpeta.
4. En el repositorio entra a `Settings > Pages`.
5. En `Build and deployment`, selecciona `Deploy from a branch`.
6. Elige la rama `main` y la carpeta `/root`.
7. Guarda. GitHub te dará una URL pública.

## QR
Cuando la landing esté publicada, usa esa URL como destino del QR del flyer.

## Google Maps
Los botones usan búsquedas de Google Maps por dirección, sin API key y sin costo.
Antes de lanzar la campaña, valida que cada búsqueda llegue al pin exacto de cada tienda.
